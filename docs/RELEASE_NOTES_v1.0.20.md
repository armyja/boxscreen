# BoxScreen v1.0.20 · 一加 16（PYB110）

本版全面重构应用与外接屏控制界面为锤子 OS（Smartisan OS）浅/暗双主题风格，新增机械推子滑块与内置离线操作图解，并针对浅色白底图标融合及横屏红星角标对齐做了精细打磨：

- **锤子 OS 风格浅/暗双主题与三段式外观切换**：以纯 Android Framework 绘制重构主界面（无任何第三方 UI 库依赖，Release APK 仅约 386 KiB），支持默认跟随系统自动切换浅色/暗色，并在控制卡片内提供「跟随系统 / 浅色 / 暗色」三段式手动切换；支持多实例与外接屏控制层实时联动，切换过程不重启界面也不中断虚拟屏输出。
- **锤子音乐风格实体机械推子滑块**：手机端虚拟屏 DPI 滑块与外接屏音量/DPI 滑块统一升级为实体凹槽推子，彻底消除半透明穿透并修复冷启动偶现的 `0×0 px` 提示条。
- **浅色白底图标轮廓优化与横屏角标对齐**：应用列表卡片升级为温润浅雾灰底板，为图标添加统一圆角瓷感底托、极细半透明轮廓描边与柔和底影，解决白底图标在浅色模式下与背景融成一片的问题；收紧图标容器宽度并提升角标层级，使竖屏及横屏宽格中的收藏红星与编辑勾选角标紧贴图标右上角。
- **外接虚拟屏状态栏与下拉面板美化**：同步锤子 OS 浅/暗视觉质感（毛玻璃状态栏、紧凑音量推子、圆角最近任务槽位、浮雕 DPI 徽章、斜切按钮、朱红分屏入口与图标+名称捷径卡片），并为外接面板隔离独立图标缓存与 `bounds` 保护，修复展开下拉面板导致主列表图标消失的问题。
- **内置离线「操作图解」与仓库矢量图解文档**：主界面右上角新增离线 18 步交互式操作图解（随应用浅/暗主题实时切换），同时更新[中文使用手册](USER_GUIDE_zh-CN.md)与 [README](../README.md)，嵌入 5 张独立 SVG 图解。
