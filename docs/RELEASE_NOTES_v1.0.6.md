# BoxScreen v1.0.6 — 一加 16（PYB110）

本版本改进虚拟屏鼠标操作，并精简外接屏快捷面板。

## 更新内容

- 虚拟屏中的每个应用可分别使用触摸或鼠标输入模式，默认使用触摸模式。
- 修复竖屏切回横屏后鼠标到不了屏幕右边界的问题；竖屏方向映射保持不变。
- 下拉快捷面板移除重复的应用搜索入口，腾出的空间用于加宽 DPI 滑块；应用搜索仍可在手机主界面使用。
- 更新触摸和方向图标，并保留快捷面板中的 DPI、横竖屏、输入模式、音量和应用快捷入口。

## 安装与升级

- 适用于一加 16（PYB110），需要 Shizuku。
- 使用 BoxScreen 正式 Release 签名，可覆盖升级并保留应用设置。若设备上装的是签名不同的 Debug 版，需要先卸载 Debug 版；卸载会清除收藏和 DPI 设置。
