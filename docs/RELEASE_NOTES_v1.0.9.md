# BoxScreen v1.0.9 — 一加 16（PYB110）

本版本让外接鼠标的右键/中键在触摸模式下可用，并修复多条输入卡顿路径。

## 更新内容

- **触摸模式下右键=返回、中键=菜单。** 之前触摸模式只认左键；实际上任何"第一下按下的键"都会被当作左键开始触摸手势，所以右键/中键看起来和左键一模一样。现在：左键仍是触摸点击，右键触发 KEYCODE_BACK，中键触发 KEYCODE_MENU，松开生效，与 Android 的点击语义一致。触摸手势进行中不触发，避免误发。鼠标模式下右键/中键仍原样透传给应用。
- **修复关闭最后一个应用后连点右键导致的「应用无响应」**。根因是三层叠加：注入按键无目标窗口可收（失败注入）、OPPO 系统对每发注入按键都会把显示搬到顶层并等待其切换动画（最长 5 秒）、以及应用退出后遗留的失效焦点 token。现在：虚拟屏上没有前台任务时完全不发键；发键先经后台线程；连点节流 250ms。
- **修复关闭应用后/切换状态栏面板时指针僵住**。鼠标与触摸事件转发也从主线程移到专用的后台注入线程，主线程不再有任何注入调用，指针始终跟手。
- 解除外接手柄屏幕绑定改在后台线程执行，避免 Shizuku 服务响应慢时阻塞界面（v1.0.8 已有，继续保留）。
- 与 v1.0.8 相同的虚拟屏、DPI、鼠标转发、快捷面板、手柄支持行为保持不变。

## 已知限制

- 右键/中键映射只在触摸模式下生效；鼠标模式下由应用自己解释。
- 连点返回时每 250ms 最多生效一次（系统侧对注入按键有显示切换等待，频率过高会卡顿输入）。
- 手柄与右键/中键注入都依赖 Shizuku 授权。
- 支持范围为一加 16（PYB110）；本次同时在一加 8（IN2010，Android 13）上验证。

## 安装与升级

- 适用于一加 16（PYB110），需要 Shizuku 授权。非 Root 环境可按 Shizuku 指引启动服务。
- 使用 BoxScreen 正式 Release 签名，可覆盖升级并保留应用设置。若设备上装的是签名不同的 Debug 版，需要先卸载 Debug 版；卸载会清除收藏和 DPI 设置。
