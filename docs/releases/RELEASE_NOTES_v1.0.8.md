# BoxScreen v1.0.8 — 一加 16（PYB110）

本版本修复外接手柄在虚拟屏中收不到输入的问题。

## 更新内容

- **外接手柄可以在虚拟屏里用了。** 之前手柄被系统绑定在手机内置屏上，即使虚拟屏上的应用拿到了输入焦点，按键和摇杆事件也不会送过去。现在 BoxScreen 在创建虚拟屏后、以及每次插入新的输入设备时，解除手柄类设备（带摇杆轴的 GAMEPAD / JOYSTICK 设备）的屏幕绑定，让系统重新按焦点投递。
- 只处理真正的手柄。部分机型会把机身上的霍尔开关、耳机孔检测也标记成 GAMEPAD，这些设备会被跳过，不会被动到。
- 解除绑定的操作放到后台线程执行，避免 Shizuku 服务响应慢时阻塞界面，导致系统弹出「应用无响应」。
- 与 v1.0.7 相同的虚拟屏、DPI、鼠标转发和快捷面板行为保持不变；虚拟屏仍然跟随外接显示器当前分辨率，不写死参数。

## 已知限制

- 手柄支持依赖 Shizuku 授权（与鼠标转发一致）。没有 Shizuku 时手柄仍按系统默认行为工作，虚拟屏内收不到输入。
- 按键与摇杆由系统按焦点投递，不做事件转发；如果某个应用自己声明窗口不可获焦（例如部分移植游戏），它仍然收不到手柄输入。
- 支持范围为一加 16（PYB110）；本次修复同时在一加 8（IN2010，Android 13）上验证。

## 安装与升级

- 适用于一加 16（PYB110），需要 Shizuku 授权。非 Root 环境可按 Shizuku 指引启动服务。
- 使用 BoxScreen 正式 Release 签名，可覆盖升级并保留应用设置。若设备上装的是签名不同的 Debug 版，需要先卸载 Debug 版；卸载会清除收藏和 DPI 设置。
