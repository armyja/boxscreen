# BoxScreen v1.0.7 — 一加 16（PYB110）

本版本改进 UU 远程的鼠标兼容性，并增加逐应用 DPI 显示兼容设置。

## 更新内容

- 针对 UU 远程使用专用虚拟屏配置，避免其捕获鼠标后 BoxScreen 光标无法继续操作。建议关闭 UU 远程的“沉浸式鼠标”。进入或离开 UU 远程时会重建虚拟屏，其他应用仍使用原有配置。
- 快捷面板新增逐应用的主屏 DPI 同步开关，缓解部分应用在主屏与虚拟屏 DPI 不一致时出现的文字显示异常。开启后手机主屏的文字和布局也可能变化；关闭开关、切换到未开启的应用或停止输出时会尝试恢复。部分应用可能需要重新适配，显示变化也可能有延迟。
- 外接屏快捷条和下拉面板的文字、控件及点击区域跟随虚拟屏 DPI 缩放；松开 DPI 滑块后更新，横屏和竖屏分别使用各自保存的 DPI。
- 改善主屏 DPI 变化时 BoxScreen 界面和虚拟屏输出的稳定性。

## 安装与升级

- 适用于一加 16（PYB110），需要 Shizuku 授权。非 Root 环境可按 Shizuku 指引启动服务。
- 使用 BoxScreen 正式 Release 签名，可覆盖升级并保留应用设置。若设备上装的是签名不同的 Debug 版，需要先卸载 Debug 版；卸载会清除收藏和 DPI 设置。
