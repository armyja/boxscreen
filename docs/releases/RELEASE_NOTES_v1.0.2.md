# BoxScreen v1.0.2 — 一加 16（PYB110）

本版本修复手机横竖屏切换时主界面崩溃，以及首次打开应用后列表为空、需要搜索才显示的问题。

## 修复内容

- 修复横屏切回竖屏时应用网格列数缩小时发生的崩溃，避免 BoxScreen 主界面因此退回桌面。
- 应用网格现在会在首次布局完成后填充应用，并在屏幕方向或可用宽度变化后重新排版。

## 安装与升级

- 适用于一加 16（PYB110）。
- 本版本使用与 v1.0.1 相同的发布签名，可以直接覆盖升级并保留 BoxScreen 的本地收藏和 DPI 设置。
- 如手机安装的是签名不同的 Debug 版，需要先卸载 Debug 版再安装；卸载会清除应用数据。
