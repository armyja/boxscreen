# BoxScreen v1.0.23 · 低功耗保活、液态玻璃对齐与平滑去色阶、后台任务下拉关闭

本版聚焦稳定性与视觉细节修复，解决切后台后被系统冻结引发鼠标 ANR 退出的问题，消除贴边液态玻璃错位与暗色背景色阶断层，并放开状态栏对后台应用的下拉关闭支持：

- **低功耗前台服务保活（`KeepAliveService`）**：外接屏 `Presentation` 运行期间自动挂载轻量 `specialUse` 前台服务（无 WakeLock、无后台线程或轮询，`START_NOT_STICKY`），避免手机主屏切至其他应用后被系统 Freezer 冻结并因外接屏鼠标事件触发 5 秒 ANR 强杀；停止输出或划掉应用时立即回收。
- **贴边液态玻璃面板 1:1 垂直对齐**：为 `LENS_OPTICAL_AGSL` 增加 `faceMagnify` 控制，关闭左右贴边全宽面板（外接状态栏、下拉快捷面板与手机端顶栏）的中心向外径向放大，使下方图标列从中心到两侧边缘都能与屏幕真实位置 1:1 对齐，同时保留底边倒角的高光、色散与垂直折射质感；悬浮卡片仍保留微凸透镜放大效果。
- **暗色极光背景与渐变去阶梯断层**：在 Android 13+ 为 `LiquidAuroraBackdropDrawable` 引入单 Pass 浮点 AGSL 着色器，以平滑高斯衰减替代折线三色标叠加，并在输出前加入三角交错梯度噪声（IGN）抖动消除 8-bit 暗色等高线色带；同时为液态玻璃卡片渐变与 Canvas 降级路径补全 `Paint.DITHER_FLAG` 与多停靠点平滑过渡。
- **状态栏单应用图标支持下拉关闭后台应用**：在左右边界内向下拖出底边松开时，除原有前台全屏与分屏栏关闭外，现在也可直接强停并移除非前台/后台应用任务；若目标处于后台分屏组合中会先解散该组合，且关闭后台任务不打扰或闪烁当前前台画面。
- **设备后端保持原样**：本版没有修改 OnePlus 16 / OnePlus 8 的虚拟屏创建、分屏后端或机型适配接口。

本版使用 BoxScreen 正式 Release 签名，可覆盖升级并保留设置。需要 Shizuku 授权。
