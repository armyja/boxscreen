# BoxScreen v1.0.21 · 控制面板与配置变化优化

本版收整主界面和外接屏控制面板的布局，并减少无关配置变化带来的显示刷新：

- **快捷面板布局统一**：统一截图、屏幕方向和触摸/鼠标按钮的宽度、边距与图标尺寸；优化 DPI 滑块可用宽度和分屏入口点击区域。
- **状态栏最近任务区域调整**：最近任务图标改为一致的 32dp 槽位，重新计算间距与拖动热区，使触摸区域和图标位置保持一致。
- **配置变化处理**：Activity 收到配置变化时，只在方向、尺寸、密度、字体比例、布局方向或 UI 模式变化后更新显示几何和应用网格；销毁时注销输入设备监听，并隐藏主列表滚动条。
- **设备后端保持原样**：本版没有修改 OnePlus 16 / OnePlus 8 的虚拟屏创建、分屏实现或机型接口适配代码。

本版使用 BoxScreen 正式 Release 签名，可覆盖升级并保留设置。需要 Shizuku 授权。
