# BoxScreen v1.0.15 · 一加 16（PYB110）

本版在 v1.0.14 基础上加入最近任务快捷操作与拖动分屏：

- **分屏使用当前前台任务**：点击分屏时读取虚拟屏实际前台任务作为第一栏；关闭上层应用后露出的全屏应用仍可直接分屏。
- **状态栏显示 Android 最近任务**：状态栏图标来自系统最近任务，同一应用按包名去重；点击图标可将对应任务切换到虚拟屏。分屏中的应用仍保留在最近任务列表中。
- **分屏入口保持可用**：关闭当前前台应用后，如果虚拟屏还有全屏任务，分屏按钮仍会显示。
- **拖动应用进入分屏**：从状态栏图标或下拉面板应用卡片向左/右拖出并在原上下边界内松开，即可指定分屏栏。全屏时当前应用保留在另一栏；已有分屏时可替换目标栏，或将另一栏已有应用最大化。
- **拖动状态栏图标管理应用**：拖到图标左上方松开，可强制停止并在原全屏/分栏位置重新启动该应用；拖到图标下方、且仍在原 X 范围内松开，可强制停止并关闭该可见应用。拖动过程中状态栏不会自动隐藏。
- **状态栏交互响应更快**：显示及移开后的收起等待时间调整为 100 毫秒。
