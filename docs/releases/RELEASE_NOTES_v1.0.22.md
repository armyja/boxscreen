# BoxScreen v1.0.22 · 独立设置页、光学液态玻璃主题与应用内更新检查

本版新增独立设置页、光学液态玻璃双明暗主题、GitHub Release 应用内检查更新、新版启动图标，并对截图预览、分屏选择器与外接屏控制面板进行全面打磨：

- **独立设置页与导航收整**：首页右上角改为设置入口并移除标题栏冗余图标，精简帮助文档标题与文案；设置页分组提供外观、显示系统应用、内置离线帮助文档与关于/更新，取消标题栏图标按压放大动画。
- **光学液态玻璃双明暗主题**：保留锤子浅/暗双主题并新增液态玻璃浅/暗主题，主题风格与明暗模式独立保存；Android 13 及以上基于 `RuntimeShader` 与 `RenderEffect` 渲染背景模糊、折射色散与定向高光，Android 10–12 提供半透明视觉回退；手机顶栏严格裁切至顶栏高度，外接屏下拉面板底边平直无黑角。
- **水滴透镜滑块与背景明暗自适应**：外接状态栏音量、快捷面板 DPI 与手机端 DPI 滑块升级为单体内折射水滴样式；浅色液态玻璃下外接状态栏与快捷面板实时采样底层画面亮度，遇到深色壁纸或深色应用时自动切换高对比文字与按钮配色。
- **截图预览、分屏选择器与状态栏打磨**：截图浮动缩略卡片与居中大图预览收紧按钮尺寸并完整适配四套主题；分屏应用选择器与分栏菜单适配液态玻璃效果；外接状态栏将电量与充电闪电/已接电插头图标分离，左侧控件保持等距排列。
- **新版启动图标与更新检查**：采用深石墨背景搭配居中银铝双屏显示器自适应图标（支持系统单色图标）；设置页「检查更新」后台查询最新正式 Release 并支持浏览器下载官方 APK，「发行说明与历史版本」直达 Releases 页面。
- **文档目录归档**：按使用手册、发布说明、真机测试和设计方案归档 `docs/` 目录，并保留原使用手册链接兼容跳转。
- **设备后端保持原样**：本版没有修改 OnePlus 16 / OnePlus 8 的虚拟屏创建、分屏实现或机型接口适配代码。

本版使用 BoxScreen 正式 Release 签名，可覆盖升级并保留设置。需要 Shizuku 授权。
