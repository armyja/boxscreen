# BoxScreen v1.0.12 — 一加 16（PYB110）

本版本新增虚拟屏**分屏**：同一个虚拟屏里左右（竖屏上下）并排两个应用，各自独立运行。

## 新增功能

- 快捷面板新增“分屏”按钮：当前应用留在左栏（竖屏为上栏），空出的一栏出现应用选择器，选中即在该栏启动。选择器优先列出最近打开过的应用。
- 两栏首尾相接，中间没有黑边或缝隙；分界线由一个 12×64 像素的半透明滑块标示，位置在画面高度约 18% 处，避开居中弹窗和悬浮输入法。
- 滑块默认不显示，鼠标靠近分界线（水平约 24 像素、垂直约 44 像素以内）才出现，鼠标离开即消失。
- 拖动滑块调整比例，拖动时显示白色落点线，松开生效；单栏宽度按 20:9 限制，避免窄到无法使用。
- 按住滑块不拖直接松开（位移小于 4 像素）可交换左右两栏。
- 长按滑块约半秒弹出分栏菜单：`─` 最小化、`□` 最大化、`✕` 关闭。两组按钮分别贴在屏幕左右（竖屏上下）两侧的应用旁边。
- 最小化与最大化只隐藏应用、不结束进程；从选择器重新选中被隐藏的应用时，会复用原有 Task，带回原来的状态。
- 关闭（`✕`）才会强制停止该栏应用；另一栏不受影响。
- 分栏菜单按屏幕上的实际位置区分左右，交换窗口后仍然操作你看到的那一侧。

## 修复与改进

- 修复应用列表在 DPI 切换或更新后可能整块消失的问题：面板密度改为固定值，网格在布局未就绪时保留内容并持续重试，不再出现“清空后填不上”的空列表。
- 安装新版本后重新打开应用，会接回仍在运行的虚拟屏与分屏会话，不再出现“画面还在但面板不认识”的错位状态。
- 快捷面板移除了“全屏”按钮（最大化改由分栏菜单承担），面板只保留“分屏”。
- 应用内跳转（如打开链接、分享面板）导致的横竖屏往返不再打断分屏布局。
