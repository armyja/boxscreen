# BoxScreen v1.0.10 — 一加 16（PYB110）

本版本修复 v1.0.9 引入的一个回归：打开应用后白色指针不再出现在外接屏。

## 问题描述

v1.0.8 起为修复外接手柄而加入的"手柄屏幕绑定清理"，在 v1.0.9 部分机型上误伤了鼠标：部分 2.4G 接收器（如 Compx 接收器）和蓝牙键盘的输入设备会在合并后的 sources 里携带 JOYSTICK 位，于是每次创建虚拟屏时，自动启用鼠标路由成功后几毫秒内，清理逻辑又把同一个鼠标的屏幕关联删掉了。表现是打开应用后白色指针不出现在外接屏，需要手动"关闭鼠标→开启鼠标"才能恢复。

## 修复

- 手柄清理逻辑跳过一切报告鼠标/触摸板指针类或键盘类的设备——2.4G 接收器、蓝牙键盘不会再被误清，真实手柄（仅 GAMEPAD/JOYSTICK）照常清理。
- 清理手柄关联调整为在启用鼠标路由**之前**执行，消除"先绑定后删除"的竞态。
