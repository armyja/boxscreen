# BoxScreen v1.0.13 — 一加 16（PYB110）

本版本重点是把外接画面的输出链路重写了一遍：横屏大画面告别重复帧，虚拟屏与分屏的容器不再残留，控制界面回到手机主屏。

## 新增与改进

### 输出更顺滑（自动，无需设置）

- 横屏且输出画面大于约 1200p（如 2560×1440）时，BoxScreen 会自动把画面在应用内缓冲一帧再送外接屏：外接屏每次合成都有完整的一帧可用，不再出现「匀速滚动时偶发卡一下」。
  - 实测（同一动画、2560×1440@60、10 秒窗口）：旧链路外接屏只呈现 562 帧（61 次漏帧），新链路呈现 616 帧（与应用产帧完全一致，仅 3 帧轻微延迟）。
  - 代价：额外约 16 ms 延迟、约 7% 单核 CPU。看视频、刷网页无感；需要极低延迟的场景可停止输出再重新开始以外的方式规避（该路径按分辨率自动启用）。
- 1080p 及以下直接输出，延迟与 CPU 开销保持最低。
- 竖屏沿用原有的图层旋转输出路径（本版未加入缓冲，保证画面方向与鼠标对位不变）。
- 横屏输出改用独立 SurfaceView 图层直出，去掉了原来每帧重绘整个窗口的开销（旧路径每 5 秒 233–247 次整窗重绘，新路径 0 次）。

### 分屏

- 退出分屏、重新进入分屏或停止输出时会清理虚拟屏上的分屏容器，不再累积隐藏的残留任务（清理前实测残留 40+ 个根容器）。
- 从分屏回到单应用时优先复用仍在运行的那个应用任务，不再重新冷启动。
- 分栏菜单（长按分隔滑块：最小化 / 最大化 / 关闭）已按「屏幕上看到的那一侧」执行，交换窗口后不再操作错边。

### 控制界面

- 在虚拟屏里打开 BoxScreen 时，点击应用会把控制界面带回手机主屏，并在原来的虚拟屏上启动该应用；右上角关闭按钮也能正常关闭虚拟屏里的 BoxScreen。

### 稳定性

- 截图保存、按键注入检查、分屏状态轮询移出主线程，减少主线程卡顿。
- Shizuku 显示服务在停止输出后会正常退出，不再长期驻留。

## 已知限制

- 竖屏目前不使用缓冲输出（画面正常，但可能保留原先的轻微重复帧），后续版本再处理。
- 缓冲输出会在停止输出并重新开始后按当前分辨率重新判定。
