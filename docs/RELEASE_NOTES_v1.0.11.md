# BoxScreen v1.0.11 — 一加 16（PYB110）

本版本新增虚拟屏截图功能，可从外接屏快捷面板截取正在显示的画面。

## 新增功能

- 快捷面板新增截图图标，直接截取虚拟屏画面，不包含手机上的快捷面板或状态栏。
- 截图保存到图库的 `Pictures/Screenshots` 文件夹，并在外接屏显示预览。
- 点开预览后可删除截图，或在外接屏使用系统默认图片应用打开。
- 调整截图和屏幕旋转图标，并收窄截图点击区域，避免误触相邻控件。

## 安装与升级
