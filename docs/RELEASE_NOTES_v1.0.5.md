# BoxScreen v1.0.5 — 一加 16（PYB110）

本版本为虚拟屏鼠标操作和 DPI 调节带来改进。

## 更新内容

- 增加外接屏鼠标快捷控制：顶部快捷条可调节媒体音量、切换最近应用、关闭当前应用；下拉面板可调 DPI 和切换横屏/竖屏效果。
- DPI 滑块松开后立即应用，不需要停止并重建虚拟屏。横屏和竖屏的 DPI 分开保存，范围为 140–600，每格 10 DPI。
- 修复竖屏鼠标指针贴近屏幕左边缘时白色指针消失的问题，并让指针在竖屏状态顺时针旋转 90°。
- 横竖屏切换时，鼠标指针位置按屏幕比例映射；移动方向、全屏移动范围和点击坐标保持对应。

## 安装与升级

- 适用于一加 16（PYB110），需要 Shizuku。
- 使用 BoxScreen 正式 Release 签名，可覆盖升级并保留应用设置。若当前安装的是签名不同的 Debug 版，需先卸载 Debug 版；卸载会清除收藏和 DPI 设置。
- APK：`BoxScreen-v1.0.5-OnePlus16-PYB110.apk`
- 版本：`versionName 1.0.5`，`versionCode 6`
- 许可证：MIT。
