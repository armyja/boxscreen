# BoxScreen v1.0.19 · 一加 16（PYB110）

本版支持在分屏组合状态下同时展示单应用图标，并修复分栏应用原位重启与后台组合拆散切回全屏的显示异常：

- **分屏组合状态栏同时显示两个单应用图标**：无论分屏组合处于前台还是后台保留，状态栏在显示左上/右下交叠组合图标的同时，紧邻展示组合内两个应用的独立图标；便于直接对单个分栏应用执行向左上角拖拽快速重启、下拉关闭或单击拆散切回全屏。
- **修复分屏内单应用向左上角拖拽重启失败**：强制停止应用导致系统将任务移出分栏子任务列表后，改为在原分栏内通过 `startTask` 复用并重放任务（并兜底重新 `reparent` 或按组件名在原分栏重建 Activity），不再出现“应用任务已离开原分栏”报错或分栏变空。
- **修复后台分屏拆散后切回全屏残留半屏裁剪**：后台保留的分屏组合在点击单应用拆散或切回组合内任一应用时，改为先移回全屏根任务再通过 `startTask` 触发系统前台切换过渡，清除 SurfaceFlinger 层残留的分屏裁剪与位移，保证左右两栏应用切回全屏均完整显示。
