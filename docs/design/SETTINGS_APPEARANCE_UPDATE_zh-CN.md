# BoxScreen 设置、外观与更新方案

状态：已随 v1.0.22 实现并在 OnePlus 16 真机完成验证（基线 v1.0.21 / `ec98b3e`）。

已确认两项设计：应用内检查更新，浏览器下载 APK，Android 确认安装；液态玻璃在 Android 13+ 使用 `LiquidGlassEngine`（`RuntimeShader`/`RenderEffect`）渲染光学玻璃，API 29–32 提供半透明回退。

## 外接屏状态栏

- 现有 `MainActivity.statusBarLabel()` 将时间和电量拼为一段文字，绘制时用栏高的 65% 作为基线。音量滑块和操作图标沿中心线排列。改用字体度量计算基线，将时间、电量和充电状态作为一组居中后微微上移，先试 1dp，再按真机视觉调整。
- 将电量百分比与供电、充电状态分开读取。使用 `ACTION_BATTERY_CHANGED` 初始化并更新缓存，按界面生命周期注册和注销监听。实际充电显示静态闪电，已接电但未充电或已充满时显示插头，未接电只显示电量，状态未知时只展示可信信息。上一轮一加 16 的 ADB 快照是 USB 供电、80%、系统报告未充电，可用来说明为什么这两个状态要分开。
- 状态栏绘制、宽度测量和点击区域共用布局计算。电量组宽度应为充电图标和三位数百分比留出空间，使插拔电源时音量控件和最近任务位置保持稳定。仅在可见且信息变动时刷新相应区域。
- 验收覆盖横竖屏、不同 DPI、100% 电量、拔线、充电、接电暂停或充满，以及最近任务较多时的布局和点击。

## 独立设置页

- 首页右上角改为设置入口。首页保留外接屏状态、应用搜索与收藏、鼠标、横竖屏、手动黑屏、停止输出和虚拟屏 DPI。把低频设置移出主界面。
- 设置页分四组：**外观**（主题风格和明暗模式）、**应用列表**（显示系统应用）、**帮助**（复用离线操作图解）、**关于**（行内「检查更新」与版本胶囊、「发行说明与历史版本」）。已安装版本从 PackageManager 读取。
- 使用全屏设置窗口作为独立页面，由当前 Activity 持有，通过已有偏好设置保存变更。投屏和鼠标由原有会话继续持有。主页、设置页和外接面板收到外观变更后刷新样式；应用筛选变化后更新列表。验收时在分屏输出中进入设置、查看指南、切换外观并返回，确认画面、分屏任务和指针连续可用。

## GitHub Release 更新

- 检查按钮在后台请求固定仓库 `armyja/boxscreen` 的最新正式 Release，不在 APK 中配置 GitHub 凭据。按数字段比较稳定版标签与已安装版本号，过滤无法识别的标签。界面区分检查中、已有新版、已是最新版、网络失败或缺少 APK，并防止连点触发并发请求。
- 发现新版时展示版本号和说明，提供官方 APK 的浏览器下载入口。资产选择应明确匹配项目的正式 APK 命名，遇到缺失或歧义则打开对应 Release 页面。设置页同时提供「发行说明与历史版本」入口直接打开 GitHub Releases 页面，即使 API 请求失败也可查看或下载各版本。
- 浏览器负责下载，Android 负责安装确认。应用无需新增安装权限。发版先把正式签名 APK 上传到草稿，再公开 Release。验收覆盖版本比较（如 `1.0.9` 到 `1.0.22`）、断网或限流、缺少资产，以及用正式签名 APK 覆盖升级后保留收藏、DPI 和主题。
- 参考 [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。

## 液态玻璃主题与启动图标

- 主题风格提供 **锤子** 和 **液态玻璃**，与 **跟随系统 / 浅色 / 暗色** 分开保存。将颜色、圆角、边框和表面样式从 `SmartisanPalette` 提取为两套风格共用的定义，覆盖主页、设置页、外接状态栏、下拉面板、截图缩略卡片与居中预览弹窗、分屏应用选择器与分栏菜单。布局与触控热区共用。
- Android 13+ 通过 `LiquidGlassEngine` 使用 `RuntimeShader` / `RenderEffect` 实现背景高斯模糊、Snell 折射与色散、定向高光亮边与单体内折射水滴滑块；API 29–32 提供半透明视觉回退。手机顶栏严格裁切到顶栏高度，避免模糊下方正文；外接屏状态栏与快捷面板通过 `PixelCopy` 实时采样底层画面亮度，在浅色液态玻璃遇到深色壁纸或深色内容时自动切换高对比配色，下拉面板底边平直且保留柔阴影。
- 新启动图标采用深石墨阳极氧化质感背景搭配居中银铝质感双屏显示器图形，含自适应前景、背景及系统单色版本（无白底与白色机身融合问题），经桌面与最近任务实机验收确认。
