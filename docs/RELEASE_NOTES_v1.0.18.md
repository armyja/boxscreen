# BoxScreen v1.0.18 · 一加 16（PYB110）

本版优化分屏组合切换体验、任务栈返回顺序与半屏显示遮挡，并补充自动化测试文档：

- **分屏组合后台保留与交叠图标**：分屏期间打开其他应用时，原有分屏组合（单组）保留在后台不再自动拆散；状态栏以左上/右下交叠图标合并展示，不再重复显示单应用图标。点击组合图标可恢复分屏（兼容后台期间切换横竖屏），直接启动组合内单个应用则拆散组合并切至全屏。
- **修复任务栈顺序与自动切回组合**：后台保留分屏不再压至任务栈底；在虚拟屏服务内维护精确任务栈，关闭上层全屏应用（点击右上角 `×` 或状态栏下拉关闭）后会自动切回其下方的分屏组合，多层应用依次关闭也能保持正确返回顺序。
- **状态栏组合图标手势**：
  - 在组合图标左右边界内**向上拖过上边界**松开：无损拆散组合，不结束任一应用（前台/后台均支持）。
  - 在组合图标左右边界内**向下拖过下边界**松开：强制停止并关闭组合中的两个应用。
- **修复半屏选区左侧透底 / 露出底层应用**：分屏进入半屏选区时重置子任务窗口模式、提升分屏根容器图层层级并增加纯黑不透明背景遮罩，避免半屏状态下底层全屏应用覆盖或透过透明窗口显示在左侧。
- **文档**：新增[真机自动化测试指南](TESTING_GUIDE_zh-CN.md)，并同步更新[中文使用手册](USER_GUIDE_zh-CN.md)。
